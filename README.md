## 🧩 What I work on

At IJO-BS I work on **Imper**, a multi-agent LangGraph system where planner, researcher, judge, and writer agents gather references, check them against live scholarly sources, fact-check claims, and verify every citation before it's used.

- **Reliable by design:** bounded plans with tool budgets and hard stops, scoped retrieval, and MongoDB checkpoints so a crashed run resumes where it left off
- **Measured, not guessed:** reference gathering went from about 60 minutes for 200 references to about 5 minutes for 150
- **Verified:** every candidate is screened against Crossref, DOAJ, Semantic Scholar, and Unpaywall
